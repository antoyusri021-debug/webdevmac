MENU KONEKSI LIVE

Menghubungkan Akun TikTok Live

Ikuti langkah berikut untuk menghubungkan aplikasi dengan siaran TikTok Live Anda.

1. Masukkan Username TikTok

Ketik username akun TikTok yang sedang melakukan siaran langsung tanpa menggunakan simbol @ Contoh: webdev.

2. Aktifkan Koneksi

Klik tombol Aktifkan Koneksi untuk memulai proses sinkronisasi antara aplikasi dan akun TikTok Live Anda.

3. Tunggu Status Terhubung

Jika koneksi berhasil, status aplikasi akan berubah menjadi Terhubung dan siap menerima event live.

ASSETS OVERLAY

Cara Menggunakan Overlay

Ikuti langkah berikut untuk menggunakan overlay pada OBS Studio atau TikTok Live Studio.

1. Pilih Overlay

Pilih salah satu overlay yang ingin digunakan dari daftar Assets Overlay.

2. Pilih Tema

Jika tersedia beberapa tema, pilih tampilan yang sesuai dengan kebutuhan live streaming Anda.

3. Salin Link Overlay

Klik tombol Copy Link untuk menyalin alamat overlay yang telah dipilih.

4. Tambahkan ke Software Streaming

Tempelkan link overlay ke Browser Source di OBS Studio atau TikTok Live Studio.

CHAT OVERLAY

Cara Menggunakan Chat Overlay

Ikuti langkah berikut untuk menampilkan chat TikTok pada overlay streaming.

1. Aktifkan Monitor Chat

Buka menu Monitor Chat, lalu aktifkan opsi Auto agar pesan chat terbaca secara otomatis.

2. Uji Tampilan Chat

Klik tombol Trigger Chat untuk menampilkan pesan percobaan dan memastikan overlay berjalan dengan baik.

3. Pilih Tema & Layout

Pilih tema yang diinginkan, lihat hasilnya pada View Style Preview, lalu atur mode Vertikal atau Horizontal sesuai kebutuhan.

4. Atur Jumlah & Durasi Chat

Tentukan jumlah chat yang ditampilkan. Kolom detik berfungsi mengatur berapa lama chat tampil sebelum menghilang. Isi 0 jika ingin chat tetap tampil.

5. Tambahkan ke OBS / TikTok Live Studio

Salin URL Overlay, lalu tempelkan ke Browser Source pada OBS Studio atau TikTok Live Studio.

6. Gunakan Monitor Chat di OBS

Klik Salin URL Dock, lalu di OBS buka Docks → Custom Browser Docks, tempelkan URL tersebut dan klik Apply.

SONG REQUEST

Cara Menggunakan Song Request

Fitur Song Request mengambil sumber musik dari YouTube Music dan YouTube untuk diputar secara otomatis saat live.

1. Aktifkan Overlay Player

Salin URL dari Pilihan Tema Overlay Player lalu tambahkan ke OBS atau TikTok Live Studio. Overlay ini wajib digunakan karena menjadi sumber pemutar audio lagu.

2. Overlay Daftar Lagu (Opsional)

Gunakan Overlay Daftar Lagu (Queue) jika ingin menampilkan antrean lagu yang sedang menunggu untuk diputar.

3. Overlay Petunjuk Request

Tambahkan overlay petunjuk untuk menampilkan format request lagu kepada penonton.

4. Pilih Mode Request

Mode Free memungkinkan semua penonton request lagu. Mode Gift mengharuskan penonton mengirim minimal 1 gift untuk setiap request lagu.

5. Overlay Notifikasi Ditolak

Digunakan pada Mode Gift untuk menampilkan peringatan jika penonton mencoba request lagu tanpa mengirim gift terlebih dahulu.

6. Manual Song Request

Admin atau host dapat menambahkan lagu secara manual melalui kolom input yang tersedia.

7. Kelola Daftar Request

Pada menu Daftar Request Masuk, admin dapat memutar lagu secara langsung, menghapus lagu, menggunakan tombol Next Song, atau Reset untuk mengosongkan seluruh antrean lagu.

8. Mode Karaoke (Lock System)

Aktifkan Mode Karaoke untuk mengunci sistem agar penonton tidak bisa melakukan request lagu lewat chat maupun gift. Admin tetap dapat menambahkan lagu secara manual melalui fitur Manual Song Request meskipun mode ini sedang aktif.
