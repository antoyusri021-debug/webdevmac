MENU KONEKSI LIVE

Menghubungkan Akun TikTok Live

Ikuti langkah berikut untuk menghubungkan aplikasi dengan siaran TikTok Live Anda.

1. Masukkan Username TikTok

Ketik username akun TikTok yang sedang melakukan siaran langsung tanpa menggunakan simbol @ Contoh: webdev.

2. Aktifkan Koneksi

Klik tombol Aktifkan Koneksi untuk memulai proses sinkronisasi antara aplikasi dan akun TikTok Live Anda.

3. Tunggu Status Terhubung

Jika koneksi berhasil, status aplikasi akan berubah menjadi Terhubung dan siap menerima event live.

ASSETS OVERLAY

Cara Menggunakan Overlay

Ikuti langkah berikut untuk menggunakan overlay pada OBS Studio atau TikTok Live Studio.

1. Pilih Overlay

Pilih salah satu overlay yang ingin digunakan dari daftar Assets Overlay.

2. Pilih Tema

Jika tersedia beberapa tema, pilih tampilan yang sesuai dengan kebutuhan live streaming Anda.

3. Salin Link Overlay

Klik tombol Copy Link untuk menyalin alamat overlay yang telah dipilih.

4. Tambahkan ke Software Streaming

Tempelkan link overlay ke Browser Source di OBS Studio atau TikTok Live Studio.

CHAT OVERLAY

Cara Menggunakan Chat Overlay

Ikuti langkah mudah berikut untuk menampilkan dan memantau chat TikTok secara otomatis.

1. Hubungkan Live di Menu Koneksi

Buka menu Koneksi Live, lalu sambungkan ke live streaming lu. Menu ini juga menyediakan akses langsung untuk mengaktifkan pemantauan chat.

2. Pilih Tema di Assets Overlay

Masuk ke menu Assets Overlay. Di sini tema sudah dibagi menjadi dua kategori instan: Chatbox (untuk tampilan *stream*) dan Dock Chat (untuk monitoring).

3. Klik untuk Mengaktifkan Tema

Gak perlu ribet atur settingan lagi! Cukup klik pada tema yang lu suka, dan tema tersebut akan otomatis langsung aktif dan siap digunakan.

4. Pasang Dock Monitoring Chat di OBS

Pada bagian Dock Chat di menu Koneksi Live, silakan klik tombol Salin URL Dock. Di OBS Studio, buka menu Docks → Custom Browser Docks, tempelkan URL-nya, lalu klik Apply.

5. Tambahkan Chatbox ke Software Streaming

Salin URL dari tema Chatbox yang sudah lu pilih, lalu tambahkan sebagai Browser Source baru di OBS Studio atau TikTok Live Studio lu. Chat akan langsung ngerender otomatis saat live!

REQUEST MUSIK

Cara Menggunakan Song Request

Ikuti langkah berikut untuk mengaktifkan fitur request lagu otomatis dari penonton saat live streaming.

1. Pilih Tema di Menu Request Musik

Buka menu Request Musik, lalu pilih tema Overlay Player Musik yang sesuai dengan keinginan lu. Sifatnya otomatis aktif begitu diklik.

2. Pasang Overlay Player ke Software Streaming

Salin URL dari tema Player Musik yang sudah dipilih, lalu tambahkan sebagai Browser Source di OBS Studio atau TikTok Live Studio. Overlay ini wajib dipasang karena berfungsi sebagai sumber pemutar audio lagu.

3. Buka Kontrol Panel Monitoring

Setelah overlay terpasang, buka tombol Kontrol Panel yang tersedia untuk memantau antrean, menyetujui, atau memutar musik yang masuk dari penonton secara *real-time*.

4. Atur Mode Request (Free / Gift)

Di dalam panel, lu bisa menentukan hak akses. Mode Free membebaskan semua penonton untuk request, sedangkan Mode Gift otomatis menyaring request hanya dari penonton yang mengirim gift.

5. Kelola Antrean & Mode Karaoke

Gunakan tombol kendali untuk skip lagu (*Next Song*) atau mengosongkan antrean. Aktifkan Mode Karaoke (Lock System) jika ingin menutup request dari penonton buat sementara waktu, sehingga hanya admin yang bisa memasukkan lagu secara manual.

STREAM TOOLS

Cara Menggunakan Stream Tools

Optimalkan kualitas siaran lu dengan alat bantu kontrol kamera, teks otomatis, dan transisi scene interaktif.

1. Fitur Live Caption (Teks Berjalan/Statis)

Gunakan alat ini untuk membuat running text, pengumuman, atau subtitle instan di layar live lu. Cukup ketik teks pada kolom, sesuaikan gaya, dan salin URL-nya ke software streaming sebagai Browser Source.

2. Kamera Slider (Gerakan Kamera Dinamis)

Atur pergerakan pan, zoom, atau panning scene kamera secara halus (smooth). Lu bisa bikin efek kamera bergerak otomatis atau mengatur transisi posisi kamera lewat kontrol slider instan yang tersedia.

3. Kamera Switcher (Pindah Angle Cepat)

Kelola multi-kamera atau banyak angle dalam satu panel. Lu bisa pindah dari Kamera 1, Kamera 2, atau ke scene closeup secara instan hanya dengan sekali klik tombol hotkey pada kontrol panel tanpa perlu menyentuh OBS langsung.

4. Gift Scene Switcher (Auto Transisi via Gift)

Bikin live lu makin interaktif! Fitur ini otomatis memindahkan scene OBS (misalnya ke scene khusus 'Spesial Thanks' atau 'Efek Heboh') begitu mendeteksi ada penonton yang mengirimkan gift tertentu sesuai dengan trigger yang lu pasang.

5. Integrasi Kontrol Berjalan

Pastikan websocket koneksi live lu terhubung dengan lancar agar perintah dari fitur Kamera Switcher dan Gift Scene Switcher bisa langsung mengeksekusi perubahan scene di OBS Studio / TikTok Live Studio secara real-time.
